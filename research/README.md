## 一、最该先知道的一件事：术语要分清

两份报告共同指向同一个高频误解：

| 术语 | 含义 | 谁在做 |
|---|---|---|
| **在线测评 / 认知测评 / OA** | 行测类能力测验 + 性格问卷，网申后几乎人人都做 | 京东、国央企、大厂非技术岗**都做** |
| **笔试 / 机试** | 专业知识或编程题，按岗位下发 | 技术岗、专业岗才做 |

京东明确分两套（JDS 技术笔试 vs TET 测评），国央企则通常合并成一张卷：行测 + 综合知识 + 专业知识。

## 二、两条主线的结构性差异

| 维度 | 互联网大厂（非技术岗） | 国央企 |
|---|---|---|
| 计时方式 | **单题独立倒计时** 60~90 秒，不可回退 | 整卷统一计时（如国家电网 165 题左右，120~180 分钟，两个二手来源不一致） |
| 压力来源 | 节奏（会做但做不完） | 广度（专业知识占比可达 80%） |
| 行测模块 | 常见**三块**：言语 + 资料 + 图形 | **五模块齐全**：言语 + 数量 + 判断 + 资料 + 常识 |
| 特有内容 | 迫选式性格问卷（如京东 98 题） | 企业文化、行业战略、申论/公文、英语 |
| 命题方 | 第三方平台（北森等） | 自建平台，部分全国统考 |

## 三、行测 keyword 速查（完整 88 行见 guoqi-xingce.md 第 5 节）

- **言语**：语境对应（反义/并列/递进/解释）、标志词（但是/然而/甚至/即）、语素差异、程度轻重、感情色彩；片段阅读看中心句位置 + **对策优先**；细节题防**偷换概念/时态/范围**。
- **数量**（国央企常见，京东测评证据缺失）：工程（赋值法）、行程（相遇看和追及看差）、利润（利润率分母是成本）、排列组合（捆绑/插空/隔板）、概率（至少一个用补集）、容斥、最值（保证 = 最不利 + 1）。
- **判断**：图形推理四类——位置（平移/旋转/翻转）、样式（去同存异、**黑白运算**）、数量（点线面角素、笔画数）、属性（对称/曲直/开闭）；逻辑判断的可能性推理**几乎全为加强削弱**。
- **资料分析**：基期现期、同比环比、比重、平均数、倍数、混合增长（线段法）、年均增长；最大陷阱是**「A 比 B 多 n 倍 = (n+1)B」**与**百分点 vs 百分数**；核心是**截位直除**等估算而非精确计算。
- **常识**：时政 → 法律（新法、民法典）→ 经济 → 文史 → 科技地理；国央企额外有**企业文化与行业战略**（公认送分题）。

## 四、读这两份报告时的三条注意事项

1. **凡是标「同类型示例，非真题」的例题，都不是真题。** 两家官方都从未公开发布测评真题原文；网络流传的「京东真题」基本来自题库贩子拼接。
2. **看置信度分级。** 两份报告都开篇设了 ①官方/可验证 ②二手（含来源利益动机标注）③推断 三层。二手层里，卖 AI 笔试工具的商业站存在明显利益冲突，涉及监考细节的表述要打折看。
3. **「检索不到」不等于「不存在」。** 例如「京东测评不考数量关系」是归纳自笔经缺失，而非证实；已在该报告第 2.2 节显式标注为信息缺口。
