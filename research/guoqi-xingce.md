## 0. 置信度说明

本文所有结论按可信度分为三层，正文中以标签标注。

### ① 官方 / 公告等可验证信息（高置信）

- 企业官方招聘平台、考试大纲、《公共与行业知识题库》等官方发布物。
- 典型如国家电网招聘平台发布的考试大纲与题库、各企业招聘公告中的考试形式说明。
- **限制**：多数国央企只公布考试**范围**与**形式**（如「机考、120 分钟、客观题」），极少公布逐题分值、真题原文或通过分数线。因此「官方可验证」通常只覆盖结构与范围，不覆盖具体题量与难度。

### ② 培训机构 / 论坛二手信息（中置信，需交叉验证）

- 华图、中公、粉笔、成公、高顿（上岸鸭）等机构发布的考情分析。
- 牛客网笔试讨论帖、应届生论坛笔经、知乎考情帖、小红书复盘。
- 这类信息的两类典型问题：
  1. **机构内容常带引流/卖课属性**，且标题年份经常被改写为新一届以获取流量（如标注「2027」的文章内容明显取自往届）。
  2. **经验帖样本偏差严重**：发帖者多为失利复盘或高分炫耀，中间样本缺失。
- 本文对这类信息尽量做**双来源交叉验证**；无法交叉验证的单独列出。

### ③ 推断（低置信，明确标注）

- 由公考规律、企业性质、行业惯例推导出的结论，未找到直接公开来源。
- 典型如：政审/背景调查的具体口径、各模块分值权重在非公开企业的实际分布。
- 正文中凡标注「推断」的段落，**不可作为备考唯一依据**。

### 关于「真题」的严肃声明

- 本文**不包含任何企业的真题原文**。
- 第 6 节的例题全部标注「**同类型示例，非真题**」，来源于公开教学体系（如花生十三行测体系的教学示例）与公考公开大纲样题，仅用于说明**题型形式与解析思路**。
- 网上流传的「××公司 20XX 年笔试真题」绝大多数为机构自编或改编题，**可信度低于其宣传口径**，不建议作为唯一复习材料。

## 1. 国央企笔试考什么：为什么高度接近公务员「行测 + 申论」

### 1.1 成因分析

国央企笔试大规模采用行测化命题，主要有四条原因（综合来源见下）：

1. **筛选效率与合规性**。国央企校招报名量极大（单一央企单批次可达数十万人投递），需要一种**大规模、可标准化、可机考自动判分、且不易被质疑不公平**的初筛工具。行测正好满足：全客观题、可机考、有成熟题库、评分无主观空间。
2. **命题供给现成**。公务员考试已积累数十年题库与命题规范，国央企直接复用「行测题型 + 官方题库」的成本远低于自研专业测评体系。国家电网甚至在招聘平台**公开发布《公共与行业知识题库》**供考生下载，这是「官方口径直接复用行测框架」的最强证据。
3. **考察目标一致**。国央企的用人偏好是「综合素质稳定、执行力强、服从性强、抗压」而非「技术天才」。行测考察的信息处理速度、逻辑严谨性、抗压决策能力，与实际岗位需求有一定相关性。
4. **与「申论」的对应关系**。国央企需要文字表达能力（公文写作、报告、汇报），申论/公文写作类题型因此被保留，但通常**弱化**于公务员申论，多以「材料作文」「公文写作」形式出现。

来源：[河北大学国家电网招聘考试专题交流会报道](https://cxcy.hbu.edu.cn/hdzhjycy/xwgg/xwdt/101747098743263.html)（明确提到笔试模块为「专业能力 80% + 综合知识 20%」，并现场演示行测解题技巧）、[上学吧：2026 年国家电网招聘笔试备考指南](https://ks.shangxueba.com/zn/5TS667YC.html)（提到官方公开题库与全客观题形式）、[高顿央国企：三大运营商考试内容](https://www.gwy.com/gqzp/411734.html)、[中公教育：国家能源 2026 年秋招考试内容](https://m.offcn.com/gqzp/2025/0911/199419.html)

### 1.2 为什么「行测是命题蓝本」

多数国央企笔试卷可以抽象为以下公式（②中置信，多来源支持）：

```
国央企笔试卷 ≈ 行测（40%~85%）
             + 综合知识 / 企业文化 / 时政（10%~25%）
             + 专业知识（0%~80%，视企业与岗位）
             + 性格测评（不计分或仅作参考）
             + [部分企业] 申论 / 公文写作 / 英语
```

其中**行测模块的题型、方法与公考行测几乎一一对应**：言语理解与表达、数量关系（数字运算）、判断推理、资料分析、常识判断。因此公考行测教材可以直接复用于国央企备考，只是**难度普遍低于国考**、时间更宽松（②）。

来源：[成公教育：2027 银行秋招笔试考什么，EPI 综合知识题型](https://www.cgzj.com/gqyh/14511.html)（明确「EPI 全称通用就业素质测评，本质是行测……和公考行测高度重合，备考时可以直接复用行测基础，重点练速度和取舍」）、[新东方：互联网秋招笔试行测和专业知识占比](https://mtoutiao.xdf.cn/cet4-6/202603/15122198.html)（明确「保底岗（国企/银行科技岗）行测占比可达 50%」）

**从上表可提炼的规律（②，多来源支持）**：

1. **专业知识占比与岗位技术性强弱正相关**：国家电网电工类（80%）> 南方电网电气类（60%）> 运营商技术岗（加试）> 运营商综合岗（低）> 银行职能岗（主要为综合知识）。
2. **行测占比与企业「统一程度」正相关**：全国统考的企业（国家电网、中国移动、国家能源、中石油）行测框架最标准化；各省自主命题的企业（电信、联通、烟草、电网省公司）题型差异最大。
3. **企业文化与行业时政几乎是所有国央企的必考项**，且被称为「送分题」，属于**投入产出比最高的备考区**。
4. **性格测评普遍存在但通常不计分**，主要用于岗位匹配与作答一致性核查（②）。

## 2. 行测五大模块的标准结构（国央企命题蓝本）

行测是国央企笔试与互联网非技术岗测评的共同母版，所以先把它的标准结构说清楚。

### 2.1 总览表（国考/省考基准 + 国央企常见调整）

下表「国考基准」列取自公开大纲解读与考情分析（②），国央企与互联网测评列取自各企业考情（②）。

| 模块 | 国考常见题量 | 建议用时 | 平均单题限时 | 国央企常见调整 | 互联网测评常见形式 |
|---|---|---|---|---|---|
| 常识判断 | 约 20 题 | 8~10 分钟 | ≤30 秒 | 内容替换为企业文化 + 行业常识 + 时政 | 常合并入「综合知识」或取消 |
| 言语理解与表达 | 30~40 题 | 30~35 分钟 | 约 50~60 秒 | 题量常压缩至 15~25 题 | 北森等平台保留，常为独立模块 10 题 |
| 数量关系 | 10~15 题 | 10~15 分钟 | 约 60~90 秒 | 常改名「数字运算」「数学运算」，15~25 题 | 部分平台明确降低权重 |
| 判断推理 | 约 40 题 | 30~35 分钟 | 约 45~55 秒 | 常压缩；部分企业加入「思维策略」 | 图形推理 + 逻辑推理常为独立模块 |
| 资料分析 | 约 20 题 | 20~25 分钟 | 约 60~75 秒 | 常 5~20 题，题干换成企业数据 | 资料分析为核心模块之一，10 题左右 |

来源：[教育在线：2027 国考行测常识判断备考（含题量与时间分配表）](https://www.eol.cn/kaoshi/gwy/gjgwy/202609/t20260910_2772720.shtml)、[华图：2025 年国考行测判断推理大纲解读与命题趋势](https://m.huatu.com/2024/1014/2783882.html)、[华图：2025 历年省公务员考试行测命题规律及终极预测](https://m.huatu.com/2025/0314/2806094.html)、[面灵 AI：三大运营商机考](https://www.mianlingai.com/blog/telecom-carriers-oa-exam-ai-guide-2026/)、[中公：国家能源考试内容](https://m.offcn.com/gqzp/2025/0911/199419.html)

> **重要提示（②）**：各年份、各层级的题量与分值可能调整。以国考为例，近年新增「政治理论」模块后，判断推理题量据预测相应减少约 5 道。国央企与互联网测评的题量波动更大，**以当批通知为准**。

### 2.2 模块一：言语理解与表达

**定位**：行测题量最大的模块（国考约 40 题），也是国央企笔试中保留最完整的模块。

#### 子题型结构

| 子题型 | 国考常见题量 | 核心方法 |
|---|---|---|
| 逻辑填空 | 约 20 题 | 语境分析 + 词义辨析 + 关联词 |
| 片段阅读 | 17~18 题 | 中心句识别 + 关联词定位 + 主题词法 |
| 语句表达 | 2~3 题 | 话题一致 + 逻辑顺序 + 首尾句判定 |
| 篇章阅读 | 0~10 题（副省级） | 定位 + 同义替换 |

- **逻辑填空**：语境对应（反义对应 / 并列对应 / 递进对应 / 解释对应）、标志词（但是、然而、却、甚至、更、不仅…还、即、也就是说）、搭配习惯（汇聚力量、提高水平、推动发展、履行职责、筑牢基础）、语素差异（遏制 / 遏止）、程度轻重（失望→绝望；批评→抨击→鞭挞）、感情色彩（褒义 / 贬义 / 中性）、高频成语辨析（汗牛充栋 / 浩如烟海 / 比比皆是；凤毛麟角 / 寥寥无几 / 屈指可数；殚精竭虑 / 处心积虑）

| 易错点 | 说明 |

| 忽略关联词 | 转折后、递进后、结论后才是重点 |
| 主题词遗漏 | 正确选项必须包含文段主题词 |
| 细节题陷阱 | 偷换概念 / 偷换时态 / 偷换范围 / 偷换语气 / 无中生有 / 正反颠倒 |

### 2.4 模块三：判断推理

**定位**：国考每年稳定约 40 题，四大子题型题量均衡。国央企笔试中通常被压缩，但**图形推理 + 逻辑推理**几乎必考。

#### 子题型结构与命题规律

公开大纲解读中给出了国考副省级 2018—2024 年的逐考点统计，可据此确定备考优先级。

**图形推理**（国考每年 10 题）：

| 考点类型 | 近年出现频次 | 优先级 |
|---|---|---|
| 数量类 | 每年 2~5 题 | ★★★ 最高 |
| 位置类 | 每年 0~2 题 | ★★ |
| 属性类 | 每年 0~2 题 | ★★ |
| 立体类 | **稳定每年 3 题** | ★★★ 最高 |
| 样式类 | 每年 0~2 题 | ★ |
| 功能类 | 极少（仅 2018/2019 各 1 题） | ☆ |

**定义判断**（每年 10 题）：单定义与多定义各半。**关键趋势**：自 2022 年国考起多定义题目数量增加，阅读量与难度同步上升。

**类比推理**（每年 10 题）：考点集中在**概念外延关系**与**概念内涵对应关系**两大类，语义关系与语法关系较少。

**逻辑判断**（每年 10 题）：必然性推理以**翻译推理**与**分析推理**为主；可能性推理**几乎全部是加强与削弱**。

#### 省考与国央企的差异

省联考判断推理部分每年多以 **35 题**呈现：图形推理 5 题、定义判断 10 题、类比推理 10 题、逻辑判断 10 题；逻辑判断内部约「7 道论证 + 3 道必然性推理」。随着行测增加政治理论模块，判断推理题量可能减少约 5 道（②）。来源同上。

#### 高频考点 keyword 清单

图形推理（位置类平移旋转翻转、样式类定义叠加、数量类点线面角素、属性类对称性曲直性开闭性、一笔画、立体类截面图 / 多面体 / 立体拼合 / 三视图 / 六面体）、定义判断（单定义、多定义、选是题、选非题、关键词提取）、类比推理（全同、种属、组成、交叉、反对、矛盾、因果、条件、目的、属性、功能、近反义词、语法结构）、逻辑判断（翻译推理、假言命题、逆否等价、真假推理、分析推理材料题、加强论证、削弱质疑、搭桥、拆桥、因果论证、实验论证、日常推理）

#### 易错点（②）

- **定义判断**：题干阅读难度与理解难度持续提升，专业术语（如物理、生物概念）易造成心理畏难；应对方法是从**选项间差异**反推关键词，而非死抠题干。
- **逻辑判断**：论证题的关键是**先找准论点**，选与论点最相关的选项，而非「看起来最对」的选项。
- **图形推理**：立体拼合、多面体难度高于视图题、六面体、四面体，考场上若无思路应果断舍弃，保全其他题目时间。
- **类比推理**：题量减少时难度往往上升，需有心理准备。

### 2.5 模块四：资料分析

**定位**：**投入产出比最高的模块**——方法固定、公式有限、练速度就能提分。国央企笔试中常保留，且企业数据类材料（产量、消费量、财务数据）非常适合改编。

#### 核心考点体系

设基期为 B、现期为 A、增长量为 Δ、增长率为 r：

- `Δ = A − B = B × r`
- `r = Δ / B`
- `A = B(1 + r)`
- `B = A / (1 + r) = A − Δ`
- `Δ = A × r / (1 + r)`
- 小增速近似：`A / (1 + r) ≈ A(1 − r)`

来源：[小P资料分析方法库](https://github.com/SunY0u17g/xiaop-data-analysis-skill/blob/main/references/methods.md)

#### 高频考点 keyword 清单

**增长类**：基期、现期、增长量、增长率（增速）、同比、环比、累计增速、当月增速、年均增长量、年均增长率、同比变化幅度、五年规划基期

**比重类**：比重（部分/整体）、比重升降判断（比较部分增速与整体增速）、比重变化量（单位：百分点）、两期比重比较、嵌套比重

**平均数与倍数类**：平均数增长率 `r平均 = (r分子 − r分母) / (1 + r分母)`、基期平均数、倍数关系（「A 是 B 的 n 倍」vs「A 比 B 多 n 倍」）、倍数与增长率换算

**混合类**：混合增长率（线段法）、乘积增长率 `rX = r1 + r2 + r1r2`、贡献率、拉动增长

**速算类**：截位直除、同向缩放、化除为乘、削峰填谷、尾数法、特征数字法（分数与小数的互换）、假设代入验算

#### 易错点（②，来源同上）

| 易错点 | 说明 |
|---|---|
| 百分点 vs 百分数 | 比重、利润率、指数两期相减得到的是**百分点** |
| 倍数表述陷阱 | 「A 比 B 增长 n 倍」在公考语境中通常按「多 n 倍」理解，即 A = (n+1)B |
| 正负表述 | 降幅、减少量通常只报绝对值；「变化幅度」通常取绝对值 |
| 单位陷阱 | 1 吨 = 1000 千克；1 公顷 = 15 亩；万 / 亿 / 万人次需统一 |
| 年均增长量间隔数 | 2019→2022 是 3 个间隔，不是 4 个；五年规划类题目常需**基期前推一年** |
| 首年增量陷阱 | 图表首年若给了同比增速，可以求出首年增长量，不能因为缺上一年柱形就漏掉 |
| 「最多」vs「最快」 | 增长最多比**增长量**，增长最快比**增长率** |
| 分子分母倒置 | 人均 / 亩均类指标先确认分子分母单位 |
| 混合增长率权重 | 严格权重是**基期量**；只有两分项增速接近时才能用现期量近似 |

## 3. 互联网大厂笔试的差异

互联网大厂的笔试**不采用**国央企的「行测 + 专业」结构，而是按**职位族**分裂成两条几乎不相关的路线。

### 3.1 技术岗（算法 / 后端 / 前端 / 数据 / 测试）

**典型结构**：编程题为主 + 计算机基础客观题。

| 维度 | 常见情况 |
|---|---|
| 题量 | 2~4 道编程题 |
| 时长 | 60~120 分钟 |
| 难度梯度 | 1 道简单（数组遍历）+ 2 道中等（动态规划）+ 1 道困难（图论 / 复杂数据结构） |
| 编程语言 | C / C++ / Java / Python / Go / JavaScript / C# / R 等，**视平台而定** |
| 输入输出 | 多为 **ACM 模式**，需手动处理 I/O |
| 判分方式 | 按测试用例通过比例给分，**多次提交取最高分** |
| 计算机基础 | 数据结构、算法、操作系统、计算机网络、数据库、Linux |
| 考点偏好 | **高频结合互联网业务场景**（推荐系统排序、分布式任务调度），而非纯算法理论 |

来源：[CSDN：字节跳动笔试全解析](https://blog.csdn.net/2501_91651594/article/details/148227914)、[牛客：26 年校招华为校招笔试机试高频问题（民间非官方整理）](https://www.nowcoder.com/discuss/790918305140711424)、[面灵 AI：腾讯 OA 笔试](https://www.mianlingai.com/blog/tencent-oa-exam-ai-guide-2026/)

**各厂技术岗具体结构对照（②）**：

| 企业 | 结构 | 关键细节 |
|---|---|---|
| 腾讯 | 2~3 道算法编程题 + 计算机基础客观题；60~120 分钟 | 技术岗以牛客网为主，少数岗位用腾讯内部系统；编程题难度大致对应 LeetCode 中等 |
| 字节跳动 | 3~4 道算法题，60~90 分钟 | 1 简单 + 2 中等 + 1 困难；高频结合互联网场景 |
| 华为（开发方向） | 3 道编程题，分值 100 / 200 / 300 | **达到 150 分通过**；ACM 模式；全程视频 + 桌面监控；手机扫码防作弊 |
| 华为（AI 方向，25 年秋招新增） | 20 题选择（150 分）+ 2 道 AI 编程（150 分、300 分） | **达到 180 分通过**；选择题考机器学习、深度学习、大模型基础、概率论 |
| 快手 | 10~15 道选择题 + 2~4 道编程题，编程部分约 70 分钟 | 牛客平台；编程题常包一层快手业务场景（直播间人气排名、短视频曝光量统计）；推荐算法岗可能考手写 Transformer |
| 拼多多 | 4 道传统算法题 | 难度极大，笔试淘汰率明显 |
| 京东 | 2 道算法题 + 1 道 AI Coding | 算法题难度不小 |
| 网易 | 1 道算法题 + 1 道 AI Coding | 算法题简单，时间比较充足 |
| 虾皮 | 选择题 + 3 道算法题 | 无 AI Coding |
| 阿里 | 选择题 + AI Coding | **传统算法题已取消**；选择题与投递方向挂钩（工程岗考 Java 等，AI 研发岗考 Agent 知识点） |
| 美团 | 选择题 + 编程 + AI Coding | AI Coding 按岗位分三类：设计系统、机器学习调优、设计流程思路 |

来源：[牛客华为机试帖](https://www.nowcoder.com/discuss/790918305140711424)、[面灵 AI：腾讯](https://www.mianlingai.com/blog/tencent-oa-exam-ai-guide-2026/)、[面灵 AI：快手](https://www.mianlingai.com/blog/kuaishou-oa-exam-ai-guide-2026/)、[什么值得买：大厂笔试换题整理（汇总 88 位作者面经）](https://post.smzdm.com/p/aqrxzzox/)、[CSDN：字节跳动笔试全解析](https://blog.csdn.net/2501_91651594/article/details/148227914)

**技术岗高频算法考点 keyword**：数组与字符串（前缀和、双指针、滑动窗口、KMP 简化应用）、动态规划（背包、最长子序列、区间 DP、状态压缩）、图论与搜索（BFS 最短路径、DFS 回溯、拓扑排序、并查集、LCA）、贪心（区间调度、活动选择、按单位成本排序）、树（遍历、平衡树、堆 / TopK）、哈希与模拟、二分查找、字符串处理

**技术岗易错点（②）**：

- 只过样例不代表正确：正式判分靠**隐藏测试集**，边界用例（空数组、单节点树、整数溢出、前导零）是主要失分点。
- 语言版本差异：不同在线 IDE 支持的 Python / C++ 版本不同，AI 生成代码可能含编译器不支持的语法。
- 格式细节：行末空格、输出格式严格性会影响判分。
- 编译错误直接 0 分：有考生因把自定义类写在主类内部导致编译失败而全盘归零（见牛客华为笔试复盘帖）。

### 3.2 非技术岗（产品 / 运营 / 市场 / 职能 / 管培）

**典型结构**：行测类能力测评 + 性格测评 + 专业题（主观题）。

| 维度 | 常见情况 |
|---|---|
| 平台 | **北森**占据大厂综合能力测评的绝大部分市场份额；部分企业用 SHL、牛客测评等 |
| 行测模块 | 言语理解、资料分析、图形推理为主，每模块约 10 题 |
| 单题限时 | **每题单独计时，通常 60~90 秒**（这是与国央企最大的差异：节奏压力远大于难度压力） |
| 专业题 | 案例分析、业务方案设计、行业理解类主观题 |
| 性格测评 | 题量较大（常见 90~100 题区间），不计对错，用于岗位匹配与一致性核查 |

来源：[面灵 AI：快手笔试（含北森测评结构说明）](https://www.mianlingai.com/blog/kuaishou-oa-exam-ai-guide-2026/)、[面灵 AI：腾讯 OA 笔试](https://www.mianlingai.com/blog/tencent-oa-exam-ai-guide-2026/)、[新东方：互联网秋招笔试行测与专业知识占比](https://mtoutiao.xdf.cn/cet4-6/202603/15122198.html)

**各厂非技术岗差异（②）**：

| 企业 | 结构 |
|---|---|
| 腾讯 | 产品 + HR：智力能力测试（图形推理、逻辑推理、数量关系）+ SHL 性格测评；市场及职能：智力能力测试为主；游戏策划 / 运营：数值逻辑题 + 游戏理解类主观题；设计类：部分线下笔试 |
| 字节跳动 | 行测类 + 专业题；客服等通用岗行测占比高达 50%~70% |
| 快手 | 北森：言语理解、资料分析、图形推理各约 10 题 + 性格测评（90~100 题） |
| 大厂核心岗（运营 / 产品） | 行测 50%~60%（资料分析、逻辑推理为重点）+ 专业知识 30%~40%（案例分析为主） |
| 中型厂非技术岗 | 行测 40%~50% + 专业知识 40%~50%（含 Excel 等实操题） |
| 职能岗 | 行测 50%~60% + 专业知识 30%~40%（职业素养、基础业务流程） |

来源：[面灵 AI：腾讯](https://www.mianlingai.com/blog/tencent-oa-exam-ai-guide-2026/)、[新东方](https://mtoutiao.xdf.cn/cet4-6/202603/15122198.html)、[面灵 AI：快手](https://www.mianlingai.com/blog/kuaishou-oa-exam-ai-guide-2026/)

**非技术岗三大误区（②，来源：新东方）**：

1. **死磕专业知识而不练行测速度**：行测淘汰率往往更高（有分析称运营岗 60% 的淘汰源于行测速度慢）。
2. **技术岗忽视行测**：即使占比低，未达基础分数线仍会淘汰。
3. **所有岗位用同一套备考策略**：保底岗（国企）行测占比远高于互联网冲刺岗。

### 3.3 国央企 vs 互联网大厂：结构化对比

| 维度 | 国央企 | 互联网大厂（技术岗） | 互联网大厂（非技术岗） |
|---|---|---|---|
| 命题蓝本 | 公务员行测 + 申论 | 算法竞赛 / LeetCode | 行测类测评（北森等） |
| 客观题占比 | 极高（国家电网全部为客观题） | 中（有选择题 + 编程题） | 高 |
| 编程题 | 一般没有 | **核心**（2~4 题） | 无 |
| 单题限时压力 | 中（整卷统一时间，可调配） | 低（编程题时间自由支配） | **高（单独计时 60~90 秒）** |
| 专业知识 | 常占 60%~80% | 即编程题本身 | 主观案例分析 |
| 企业文化 / 时政 | **必考** | 基本不考 | 基本不考 |
| 性格测评 | 常见，通常不计分 | 一般不设 | **普遍设置**，用于一致性核查 |
| 申论 / 写作 | 国企常见（尤其是国开行、烟草） | 无 | 主观题替代 |
| 难度定位 | 低于国考 | LeetCode 中等为主 | 低于公考 |
| 通过率参考 | 未公开 | 普遍 10%~40%（顶尖算法岗更低） | 30%~50% |

来源：综合本文前述各来源；通过率数据来自[面灵 AI](https://www.mianlingai.com/blog/tencent-oa-exam-ai-guide-2026/)（腾讯历年讨论中 10%~15% 为常见估计）、[新东方](https://mtoutiao.xdf.cn/cet4-6/202603/15122198.html)（技术岗通过率普遍低于 40%）。

### 3.4 2026 年新变量：AI Coding 成为主流题型

这是本年度**最重要的变化**，值得单列（②，基于 88 位作者面经汇总）：

**考试形式**：给一份较长的 README 需求文档 + 一套 baseline 代码，平台内置 AI 助手。考生用 AI 辅助完成开发，先跑样例，再提交运行测试集，获得分数与反馈，**提交机会通常限 20 次**。

**本质**：考的不是「一次做对」，而是「拿到反馈后如何迭代」。

**已出现 AI Coding 的企业**：阿里（传统算法题完全取消）、京东、美团、网易、快手（部分技术岗）、百度（还考提示词工程）、蚂蚁、OPPO、科大讯飞。

**高频业务场景考点**：
- **账务类流水**（发放、占用、使用、退回、到期、作废、结转，每一步都要可查）
- **虚拟时钟**（禁用真实时间，所有时间字段跟随 clock advance）
- **幂等**（重复操作、非法请求不能留下半截状态）

**三个被反复验证的坑（②）**：
1. **练习题给的错觉**：练习题验证「能跑」，正式笔试的隐藏测试集验证**业务正确性**；冒烟用例通过不代表业务逻辑正确。
2. **盲目信任平台内置 AI**：有案例显示第一版 52 分，让 AI 改完只剩 27 分，而**平台没有版本回退**——大改前必须备份当前版本。
3. **什么都交给 AI，包括读题**：有案例栽在提交目录上（未按题目要求复制 main 文件到根目录），直接 0 分。

**高分考生的共同流程（②）**：前 10 分钟不写代码（先拆解 README 形成「做题地图」）→ 挤牙膏式推进（一次一个功能块）→ 测试先行 → 提示词加护栏（不重构其他模块、不删接口、非法请求不留副作用）→ 提交前逐项审计 → 预留至少半小时。

来源：[什么值得买：阿里取消算法题，京东、美团也考 AI Coding](https://post.smzdm.com/p/aqrxzzox/)

**重要提醒**：笔试考的是「带着 AI 交付」，面试考的是「你到底懂不懂」。有案例显示面试官追问「为什么选这个设计模式」「边界条件怎么处理」时答不上来而被挂。**AI 做的每个关键决策，考生都要理解为什么**。来源同上。

## 4. 国央企特色内容

国央企笔试中有一批**互联网大厂完全没有**的内容，这是备考的重点差异区。

### 4.1 申论 / 写作

**哪些企业考**：

| 企业 / 体系 | 申论 / 写作形式 |
|---|---|
| 国家开发银行 | **明确考申论**（行测 + 申论 + 英语） |
| 中国烟草（专卖局系统）综合岗 | 写作（申论类材料作文） |
| 中国烟草部分省份综合管理岗 | 公基 + 写作 |
| 南方电网综合类岗位 | 公文写作、法律基础、马克思主义哲学 |
| 国家电网「公共与行业知识」模块 | 含形势与政策，间接考察政策理解与表述 |

来源：[东吴教育：政策性银行笔试侧重点](http://dwpx.net/?zhinan/96052.html)、[高顿：中国烟草考试内容](https://m.gwy.com/gqzp/411415.html)、[易考吧：南方电网考点总结](https://m.etest8.com/guoqi/guangdong/nfdw/13745079.html)

**备考要点（②）**：国央企申论通常**弱化于公务员申论**，更偏向「公文写作 + 材料作文」。常考文体为：议论文/策论文、通知、报告、总结、汇报材料。材料主题多围绕行业政策（双碳、能源安全、数字化转型、国企改革）与公共服务。

### 4.2 企业文化与价值观题

**这是国央企笔试中「投入产出比最高」的部分**，几乎每家企业都考，且多数被往届考生称为「送分题」。

| 企业 | 必背内容（②） |
|---|---|
| 国家电网 | 企业使命、核心价值观、发展战略、能源政策 |
| 南方电网 | 企业使命、核心价值观、**南网精神**、发展战略、新型电力系统建设方向 |
| 中国石油 | 核心价值观、**大庆精神、铁人精神、三老四严**、企业发展战略、近年重大项目、安全合规理念 |
| 国家能源集团 | 「绿色低碳、多能互补」战略、「一个目标、三型五化、七个一流」发展理念、氢能研发基地等重大项目 |
| 中国移动 / 电信 / 联通 | 企业文化、发展历程、通信行业常识 |

来源：[易考吧：南方电网](https://m.etest8.com/guoqi/guangdong/nfdw/13745079.html)、[高顿：中石油](https://m.gwy.com/gqzp/406764.html)、[中公：国家能源](https://m.offcn.com/gqzp/2025/0911/199419.html)、[上学吧：国家电网](https://ks.shangxueba.com/zn/5TS667YC.html)

**备考动作（②）**：考前 2 周集中背诵 + 关注企业官网与官方公众号动态。国家电网甚至在招聘平台直接公开《公共与行业知识题库》供下载，属于最理想的备考材料。

### 4.3 行业专业知识

**占比可能极高**，是国央企笔试与互联网笔试最大的分野。

|---|---|

| 中国联通 | 部分省份包含少量英语 |

**备考策略（②）**：银行英语题量占比不高，建议每天精读两篇财经短文保持语感，考前刷 2~3 套真题熟悉风格即可，不必投入过多时间。

### 4.5 心理 / 性格测评

**基本特征（②）**：

- **普遍存在于银行、运营商、国央企**，多数**不计分**，用于岗位匹配判断与作答一致性核查。
- 部分企业的测评是**游戏化测评**（如中国移动部分批次的性格或游戏化测评）。
- 部分银行还有**认知能力操作题**，考察反应与记忆。

**答题要点（②）**：
- **保持前后一致**比「答案完美」更重要。测评系统通过不同问法交叉验证作答一致性，刻意包装出的「完美人设」反而更容易被标记为「作答不一致」。
- 按真实情况作答，按系统提示练习几次即可上手，不需要专门准备。

来源：[成公教育：银行笔试](https://www.cgzj.com/gqyh/14511.html)、[面灵 AI：三大运营商](https://www.mianlingai.com/blog/telecom-carriers-oa-exam-ai-guide-2026/)、[面灵 AI：快手（北森测评一致性说明）](https://www.mianlingai.com/blog/kuaishou-oa-exam-ai-guide-2026/)

### 4.6 政审 / 背景调查相关提示

> ⚠️ **本节以③推断为主**。调研过程中未找到国央企笔试环节公开、权威的政审实施细则。以下为行业普遍性描述，**不可作为唯一依据**，具体以各企业招聘公告与录用通知为准。

- **政审 / 背景调查通常发生在笔试与面试之后的录用阶段**，不是笔试科目，但对最终录用有否决权。
- **常见核查内容（③推断，基于国企用人惯例）**：政治面貌与政治表现、学历学位真实性、档案完整性、在校期间奖惩记录、是否有违法违纪记录、涉密岗位的家庭成员情况、征信与涉诉情况。
- **笔试环节的关联提示（②）**：
  - 应聘材料须遵循「三真原则」——**真实、准确、规范**（河北大学国网招聘专题会明确提出）。资格审核贯穿招录全流程。
  - 涉密岗位（军工、航天、核电、部分电网岗位）对政治面貌、家庭成员背景的要求通常更严格（③推断）。
  - 电网、烟草等企业招录流程中明确包含「资格复审」环节，资格审查贯穿全部环节。
- **行动建议**：报考前仔细阅读当批公告的「报考条件」与「不得报考情形」；提前确认档案存放地与可调取性；如实填写所有信息，**不要在笔试报名阶段做任何不实陈述**。

来源：[河北大学：国家电网招聘考试专题交流会](https://cxcy.hbu.edu.cn/hdzhjycy/xwgg/xwdt/101747098743263.html)（「三真原则」）、[高顿：中国烟草考试内容](https://m.gwy.com/gqzp/411415.html)（资格审查贯穿招录全部环节）

## 6. basecase 题库形式（典型例题）

> ⚠️ **本节的全部例题均为「同类型示例，非真题」**。它们来源于公开教学体系（花生十三行测体系的教学示例）与公考公开大纲样题，用于说明**题型形式与解析思路**，不代表任何企业的实际考题。

### 6.1 言语理解与表达

**【例 1】逻辑填空（语境分析型）——同类型示例，非真题**

> 传统文化不是博物馆里的陈列品，而是活态传承的有机体。它需要在传承中创新，在创新中传承，否则就会______。
>
> A. 停滞不前　B. 故步自封　C. 日渐式微　D. 墨守成规

**解析思路**：
1. 找对应标志词——「否则」表**反义对应**。
2. 前文关键词是「**活态**传承的有机体」，反义即「失去活力」。
3. 逐项辨析：A 强调不前进；B 强调自满不求进步；C 强调逐渐衰落（与「活态」构成反义）；D 强调守旧。
4. 选 **C**。

**形式要点**：单空逻辑填空，四选项为近义成语/词语，考点在语境对应 + 词义辨析。
来源：[花生十三体系 言语理解](https://github.com/WangJunqing-coder/huasheng13-skill/blob/master/references/yanyu-lianjie.md)

**【例 2】中心理解题——同类型示例，非真题**

> 随着人工智能技术的发展，越来越多的工作岗位被机器取代。然而，技术进步也创造了大量新的就业机会，如数据标注师、AI 训练师等新兴职业不断涌现。因此，面对人工智能，我们不必过度恐慌，而应主动适应，提升技能。
>
> 这段文字意在说明：
> A. 人工智能会取代大量工作岗位
> B. 人工智能创造了新的就业机会
> C. 应对人工智能应主动适应、提升技能
> D. 人工智能技术发展迅速

**解析思路**：
1. 定位关联词：「然而」（转折）→ 重点在后；「因此」（因果）→ 结论是重点。
2. 结论句为「不必过度恐慌，应主动适应，提升技能」，属于**对策表述**。
3. 按**对策优先原则**，选 **C**。
4. A、B、D 均为分句内容或背景，不是中心。

**形式要点**：片段阅读「意在说明」型，考点在关联词定位 + 对策优先。
来源：同上

**【例 3】语句排序题——同类型示例，非真题**

> ① 这种现象引起了社会的广泛关注
> ② 近年来，共享单车乱停乱放问题日益严重
> ③ 一些城市开始出台管理办法
> ④ 同时，企业也加强了运营管理
> ⑤ 共享单车行业逐渐走向规范
>
> A. ②①③④⑤　B. ②①④③⑤　C. ①②③④⑤　D. ②③①④⑤

**解析思路**：
1. **看首句**：①含代词「这种现象」，无指代对象，不能做首句 → 排除 C。
2. **找捆绑**：①的「这种现象」指代②的问题 → ②① 必须相邻。
3. **判顺序**：③（政府出台办法）与④（企业加强管理）是并列应对，用「同时」连接，③在④前。
4. **看尾句**：⑤「走向规范」是结果，做尾句。
5. 顺序为 ②①③④⑤ → 选 **A**。

**形式要点**：5 句排序，考点在首句排除 + 代词捆绑 + 尾句判定。
来源：同上

### 6.2 数量关系

**【例 1】工程问题（赋值法）——同类型示例，非真题**

> 一项工程，甲单独做 20 天完成，乙单独做 30 天完成。甲先做 5 天后，甲乙合作，还需几天完成？

**解析思路**：
1. 赋工作总量 = 20 与 30 的最小公倍数 **60**。
2. 甲效率 = 60 / 20 = 3，乙效率 = 60 / 30 = 2。
3. 甲先做 5 天完成 3 × 5 = 15。
4. 剩余 60 − 15 = 45；合作效率 = 3 + 2 = 5。
5. 还需 45 / 5 = **9 天**。

**形式要点**：给定时间型工程问题，通用解法是赋总量为时间的最小公倍数。
来源：[花生十三体系 数量关系](https://github.com/WangJunqing-coder/huasheng13-skill/blob/master/references/shuliang-guanxi.md)

**【例 2】利润问题（赋成本 100）——同类型示例，非真题**

> 某商店进了一批商品，按定价打 8 折出售仍可获利 20%。若按定价出售，利润率是多少？

**解析思路**：
1. 赋成本 = **100**（利润问题的标准套路）。
2. 8 折售价 = 100 × (1 + 20%) = 120。
3. 定价 = 120 / 0.8 = 150。
4. 按定价出售利润率 = (150 − 100) / 100 = **50%**。

**易错点**：利润率的分母是**成本**，不是售价；「打 8 折」是 ×0.8，不是「降价 8%」。
来源：同上

**【例 3】容斥问题（两集合）——同类型示例，非真题**

> 某班 50 人，参加数学竞赛 30 人，参加物理竞赛 25 人，两门都不参加 10 人，两门都参加几人？

**解析思路**：
1. 至少参加一门 = 50 − 10 = 40。
2. 两集合容斥公式：A∪B = A + B − A∩B → 40 = 30 + 25 − A∩B。
3. A∩B = **15 人**。

**形式要点**：两集合容斥，核心公式 A∪B = A + B − A∩B。
来源：同上

**【例 4】最值问题（最不利构造）——同类型示例，非真题**

> 袋中有红黄蓝球各 10 个，至少摸几个保证有 5 个同色？

**解析思路**：
1. 「保证」→ 用**最不利构造**。
2. 最不利情况：每种颜色都只摸到 4 个，共 3 × 4 = 12 个。
3. 再摸 1 个必然凑齐 5 个同色 → 12 + 1 = **13 个**。

**形式要点**：最不利原则，口诀「最坏加一才保证」。
来源：同上

### 6.3 判断推理

**【例 1】图形推理（数量类 / 一笔画）——同类型示例，非真题**

> 六个图形分为两组：①②⑥ 均为一笔画图形，③④⑤ 均为两笔画图形。
> 请按此规律将六个图形分为两类。

**解析思路**：
1. 图形形状各异、元素不同 → 优先考虑**数量类**。
2. 尝试数点、线、面、角均无明显规律。
3. 转向**笔画数**：数奇点（引出奇数条线的点）。
4. 奇点数为 0 或 2 → 一笔画；本题 ①②⑥ 奇点数符合一笔画特征。

**形式要点**：分组分类式图形推理，考点为数量类中的笔画数。
来源：[华图：2025 历年省公务员考试行测命题规律及终极预测](https://m.huatu.com/2025/0314/2806094.html)（原文给出的省考真题示例）

**【例 2】定义判断（多定义 / 选是题）——同类型示例，非真题**

> 相变指的是物质微观粒子在不同聚集状态间的转变。在等温等压条件下，从一相转变为另一相时吸收或放出的热量是相变潜热。第一类相变是指伴有相变潜热和体积突变的相变。第二类相变则不伴有相变潜热和体积突变，但有热容跃变。
>
> 根据上述定义，下列属于第一类相变的是：
> A. 热致变色印刷工艺采用遇热可产生色变的物质，如金属碘化物、络合物等，制成油墨在印品上形成色变层
> B. 在 1 个大气压 0℃ 的情况下，1 公斤的冰转变成同温度的水，要吸收 79.6 千卡的热量，与此同时体积亦收缩
> C. 含羞草叶茎部的叶褥含有很多水分，当叶片振动时，叶褥中的水分流向其它地方，叶片逐渐干瘪蜷缩到一起
> D. 核磁共振成像是通过使人体本身的磁场和仪器自身的磁性物质相互作用形成检测显影，进而查看到病变的位置

**解析思路**：
1. 多定义题，先定位要匹配的定义——**第一类相变**。
2. 提取关键词：**伴有相变潜热** 且 **体积突变**。
3. 逐项比对：B 项「吸收 79.6 千卡的热量」（相变潜热）+「体积亦收缩」（体积突变），完全匹配。
4. 选 **B**。

**考场技巧**：定义中的专业术语容易造成心理畏难，但只要抓住关键词即可；题干难以直接理解时，可**利用选项间的差别**反推定义要点。
来源：[华图：2025 历年省公务员考试行测命题规律及终极预测](https://m.huatu.com/2025/0314/2806094.html)（原文给出的省考真题示例）

**【例 3】逻辑判断（加强论证）——同类型示例，非真题**

> 论点：某地推广新能源汽车能有效降低城市空气污染。
> 论据：该地去年新能源汽车保有量增长 30%，同期 PM2.5 年均浓度下降 12%。
> 问：以下哪项最能加强上述论证？
> A. 该地同期关闭了两家燃煤电厂
> B. 新能源汽车行驶过程不产生尾气排放
> C. 该地新能源汽车补贴政策今年已退坡
> D. 该地去年人口增长了 5%

**解析思路**：
1. 先**找准论点与论据**，识别论证缺口：论据只给出了「同期发生」，未证明「因果」。
2. A 项是**另有他因**（削弱）；D 项无关；C 项无关或轻微削弱。
3. B 项建立「新能源汽车」与「降低污染」之间的机制联系，属于**搭桥加强**。
4. 选 **B**。

**形式要点**：可能性推理加强题型，核心方法是先找论点、再判缺口、后选搭桥。
来源：综合[华图判断推理大纲解读](https://m.huatu.com/2024/1014/2783882.html)的加强论证考点说明

### 6.4 资料分析

**【例 1】增长量计算——同类型示例，非真题**

> 某企业 2023 年营业收入为 1200 万元，同比增长 20%。问 2023 年营业收入比上年增加了多少万元？

**解析思路**：
1. 注意：题目给的是**现期值和增速**，求**增长量**，不是基期值。
2. 直接用公式 Δ = A × r / (1 + r) = 1200 × 20% / 1.2 = **200 万元**。
3. 速算要点：r = 20% ≈ 1/5，则 Δ ≈ A / (n + 1) = 1200 / 6 = 200。
4. **典型错误**：直接算 1200 × 20% = 240（这是用现期乘增速，高估了增长量）。

**形式要点**：增长量计算，高频速算为「r ≈ 1/n 时 Δ ≈ A/(n+1)」。
来源：[小P资料分析方法库](https://github.com/SunY0u17g/xiaop-data-analysis-skill/blob/main/references/methods.md)

**【例 2】比重升降判断（定性速解）——同类型示例，非真题**

> 某年某市规模以上工业增加值中，高技术产业增加值同比增长 15.2%，规模以上工业增加值整体同比增长 8.7%。问：高技术产业增加值占规模以上工业增加值的比重比上年如何变化？

**解析思路**：
1. **不要动笔长除**，先做定性判断。
2. 规则：**部分增速 > 整体增速 → 比重上升**。
3. 15.2% > 8.7% → 比重**上升**。

**形式要点**：两期比重比较题，只需比较两个增速的大小即可确定方向，这一步应先于任何除法。
来源：同上

**【例 3】比重变化量（百分点 vs 百分数）——同类型示例，非真题**

> 承上题，若现期比重为 24%，部分增速 a = 15.2%，整体增速 b = 8.7%，求比重比上年变化了多少个百分点？

**解析思路**：
1. 用公式：比重变化 = p × (a − b) / (1 + a) = 24% × (15.2% − 8.7%) / (1 + 15.2%)。
2. 先算 a − b = 6.5 个百分点（**方向已定：上升**）。
3. 24% × 6.5% ≈ 1.56%，再除以 1.152 ≈ **1.35 个百分点**。
4. **关键**：单位是**百分点**，不是百分数增长率，两者混用是最常见失分点。

**形式要点**：比重变化量计算，考场顺序为「先判方向 → 再判量级 → 最后精算」。
来源：同上

**【例 4】混合增长率（线段法）——同类型示例，非真题**

> 某企业两项业务增速分别为 3.3% 与 9.8%，低增速业务的现期值约为高增速业务的 2.5 倍。求该企业整体增速。

**解析思路**：
1. **先夹逼**：混合增速必在 3.3% 与 9.8% 之间。
2. **再看靠近谁**：低增速项权重大 → 混合值更靠近 3.3%。
3. 用线段距离估算：混合值 ≈ 3.3% + (9.8% − 3.3%) / (1 + 2.5) ≈ 3.3% + 1.87% ≈ **5.2%**。
4. 若选项为 4.5%、5.1%、6.2%、7.0%，直接选 **5.1%**。

**注意**：严格权重是**基期量**；只有当两分项增速接近时，才能用现期量近似替代基期量作为权重。
来源：同上

**（可选补充）言语理解常见的「速记口诀」（②，来源：花生十三体系）**

- 填空找对应：转折反义、并列近义、递进加深、解释同义
- 中心找关联：转折后、递进后、结论是重点
- 主题词必含：反复出现是主题，答案必含主题词
- 细节防偷换：概念、时态、范围、语气、有无、正反
- 排序看首尾：代词不做首，总结做尾句
- 工程赋值：时间给最小公倍数，效率给比例
- 容斥两集：A 加 B 减交集；容斥三集：加三减二加一
- 最不利：最坏加一才保证

## 7. 备考建议汇总（按目标企业分层）

本节为**基于前述事实的行动建议**，属③推断（策略层）+ ②（方法来自各机构经验帖）。

### 7.1 按目标企业分层

| 目标 | 备考重心 | 建议精力分配 |
|---|---|---|
| 国家电网 / 南方电网 / 国家能源 / 中石油（工科岗） | **专业知识为主**（占 60%~80%）+ 企业文化与行业时政（送分题必拿） | 专业 70% / 行测 20% / 企业常识 10% |
| 运营商（移动 / 电信 / 联通） | **行测为主** + 企业文化与通信行业常识 + 岗位专业题 | 行测 60% / 专业 25% / 企业常识 15% |
| 银行（六大行） | EPI（行测）+ 综合知识（经济金融会计）+ 英语 + 时政与行情行史 | EPI 40% / 综合知识 35% / 英语 15% / 时政 10% |
| 政策性银行 | 行测 + 申论（国开行）+ 英语 + 专业课 | 行测 40% / 英语 25% / 申论或专业 35% |
| 中国烟草 | 行测 + 公基 + 写作 + 《烟草专卖法》与行业政策 | 行测 45% / 公基与写作 35% / 行业法 20% |
| 中国邮政 | 行测五大模块 + 常识 | 行测 80% / 常识 20% |
| 互联网大厂技术岗 | 编程题（LeetCode 中等）+ 计算机基础 + **AI Coding** | 编程 60% / 计算机基础 25% / AI Coding 15% |
| 互联网大厂非技术岗 | **行测速度**（资料分析 + 逻辑推理）+ 业务案例分析 + 性格测评（真实作答） | 行测 50% / 案例 40% / 准备性格测评 10% |

### 7.2 通用备考动作

1. **先拿送分分**：企业文化、行业时政、企业发展战略——考前 2 周集中背诵，投入产出比最高。
2. **行测抓易得分模块**：资料分析 > 判断推理 > 言语理解（提速）> 常识（时政法律）> 数量关系（战略性选做）。
3. **资料分析先练正确率再练速度**：目标 1 题/分钟，正确率稳定在 80% 以上。
4. **限时模拟不可省**：国央企用整卷计时（如 120 分钟 100 题），互联网非技术岗用**单题计时**（60~90 秒/题）——两者的时间压力模型完全不同。
5. **考完归档题目与踩坑**：有考生反馈题目在不同企业间复用（②），归档对自己后续场次和同类考生都有价值。
6. **技术岗面试会深挖笔试内容**：如果笔试用了 AI 辅助，必须确保自己能解释每个关键决策，否则面试会暴露（②）。
